# Laboratory 03 - Multi-Cloud Explorer

**CCM101 - Cloud Computing**

## Overview

This laboratory activity explores and compares three major cloud computing platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

The activity covers their global infrastructure, management consoles, core cloud services, advantages, and common enterprise use cases.

## Cloud Platforms Explored

1. Amazon Web Services (AWS)
2. Microsoft Azure
3. Google Cloud Platform (GCP)
