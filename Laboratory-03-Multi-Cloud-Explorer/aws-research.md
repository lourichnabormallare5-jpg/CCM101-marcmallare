# Amazon Web Services (AWS)

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers different cloud services that allow businesses to run applications, store data, manage databases, and build networks without maintaining their own physical servers.

## Global Infrastructure

AWS operates a large global infrastructure composed of Regions and Availability Zones. A Region is a separate geographic area, while Availability Zones are isolated locations within a Region. This allows organizations to deploy applications closer to their users and improve availability and reliability.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Users can create virtual servers, configure storage, manage databases, monitor resources, and adjust security settings through the console.

## Four Core Services

### 1. Compute - Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers in the cloud. Businesses can use EC2 to run websites, applications, and other workloads.

### 2. Storage - Amazon S3

Amazon Simple Storage Service (S3) is an object storage service used to store and retrieve files and data. It can be used for backups, application files, documents, images, and other digital content.

### 3. Database - Amazon RDS

Amazon Relational Database Service (RDS) helps organizations create and manage relational databases in the cloud. It simplifies common database administration tasks.

### 4. Networking - Amazon VPC

Amazon Virtual Private Cloud (VPC) allows users to create an isolated virtual network for their AWS resources. It provides control over networking features such as subnets, routing, and security.

## Three Advantages

1. AWS provides a wide range of cloud services for different business requirements.
2. Its global infrastructure allows applications to be deployed in different geographic locations.
3. AWS resources can scale according to the changing needs of an organization.

## Typical Enterprise Use Cases

AWS can be used by enterprises for hosting websites and applications, storing and backing up data, running databases, disaster recovery, application development, and deploying scalable systems for users around the world.
