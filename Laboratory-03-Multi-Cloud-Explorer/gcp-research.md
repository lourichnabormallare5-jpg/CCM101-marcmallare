# Google Cloud Platform (GCP)

## Brief Overview

Google Cloud Platform (GCP) is a cloud computing platform provided by Google. It offers cloud services for computing, storage, databases, networking, data analytics, artificial intelligence, and application development. Organizations can use GCP to build and run applications using Google's cloud infrastructure.

## Global Infrastructure

Google Cloud operates a global infrastructure composed of regions and zones. Regions are geographic locations where Google Cloud resources can be deployed, while zones are deployment areas within regions. This infrastructure helps organizations improve application availability and serve users in different locations.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to create, configure, monitor, and manage Google Cloud resources. Users can manage virtual machines, storage, databases, networking, security, and other cloud services through the console.

## Four Core Services

### 1. Compute - Compute Engine

Google Compute Engine provides virtual machines that run on Google's cloud infrastructure. Organizations can use these virtual machines to host applications, websites, and other workloads.

### 2. Storage - Cloud Storage

Google Cloud Storage is an object storage service used to store files and other unstructured data. It can be used for backups, images, videos, application data, and other digital content.

### 3. Database - Cloud SQL

Cloud SQL is a managed relational database service. It helps organizations run relational databases in Google Cloud while reducing the work required to manage the underlying infrastructure.

### 4. Networking - Virtual Private Cloud (VPC)

Google Cloud Virtual Private Cloud provides networking functionality for Google Cloud resources. It allows organizations to create and manage virtual networks for their cloud applications and services.

## Three Advantages

1. GCP provides strong services for data analytics, artificial intelligence, and machine learning.
2. It provides scalable infrastructure that can support applications with changing workloads.
3. Google Cloud has strong support for containerized applications and Kubernetes.

## Typical Enterprise Use Cases

Google Cloud Platform can be used for hosting websites and applications, data storage and backup, database management, data analytics, artificial intelligence and machine learning, Kubernetes deployments, and building scalable cloud applications.
