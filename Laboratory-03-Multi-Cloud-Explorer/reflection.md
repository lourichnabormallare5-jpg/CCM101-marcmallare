# Mission Reflection

In this laboratory activity, I learned about the three major cloud computing platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). I learned that although these platforms provide similar services such as computing, storage, databases, and networking, each platform has its own strengths and advantages.

AWS offers a wide range of cloud services that can support different types of businesses and applications. Microsoft Azure is useful for organizations that already use Microsoft products because of its strong integration with the Microsoft ecosystem. Google Cloud Platform is also a good option, especially for data analytics, artificial intelligence, and machine learning.

This activity helped me understand that choosing a cloud platform depends on the needs of the organization. Factors such as cost, scalability, existing technologies, security, and business requirements should be considered before selecting a cloud provider.

Overall, this laboratory improved my understanding of multi-cloud computing and helped me see how AWS, Azure, and GCP can be used in real-world organizations.
