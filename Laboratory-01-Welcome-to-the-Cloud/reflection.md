# Reflection

This laboratory activity helped me understand the importance of having practical skills in cloud computing and Linux environments. Through the KillerCoda Playground, I was able to access a cloud-based Linux environment and practice basic Linux commands. I learned how to check my username, working directory, hostname, Linux distribution, kernel version, CPU information, memory, and available disk space.

I also learned how to create users, organize directories, and create Markdown files using Linux commands. These activities showed me how important it is for a cloud engineer to understand the Linux operating system because many cloud environments use Linux for managing servers and infrastructure.

Another important part of this laboratory was creating a GitHub repository for my Cloud Computing Portfolio. I learned that GitHub can be used to organize technical documentation, activities, screenshots, and other project files in one place. Using a proper folder structure makes the repository easier to understand and maintain.

Overall, this laboratory gave me a better understanding of the responsibilities of a cloud infrastructure engineer. I learned that cloud computing is not only about using cloud services but also about managing systems, organizing files, documenting work, and maintaining a professional portfolio. I believe the skills I practiced in this activity will help me as I continue learning more advanced topics in cloud computing, Linux, and IT infrastructure.
