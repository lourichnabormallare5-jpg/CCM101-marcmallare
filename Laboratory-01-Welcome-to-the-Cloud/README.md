# Laboratory 01 – Welcome to the Cloud

## Mission Overview
This laboratory activity introduces the basic concepts and practical skills needed to work with a cloud-based Linux environment.

## Objectives
- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate Linux.
- Gather basic system information.
- Organize files and directories.
- Document technical work using Markdown.
- Maintain a GitHub portfolio.

## Activities Performed
- Accessed the KillerCoda Linux Playground.
- Created a Linux user account.
- Checked system information.
- Created directories and Markdown files.
- Created a GitHub cloud computing portfolio.
